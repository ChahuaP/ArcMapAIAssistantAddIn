GGeoPilot

用自然语言完成 ArcGIS 工作流

GeoPilot 会把你的中文指令转换为可确认的 GIS 工作流。确认后，ArcMap 工具栏负责真正执行，原始数据不会被模型直接操作。

首次使用：打开 ArcMap，点击 GeoPilot 工具栏里的“启动AI后台”或“显示控制台”，在网页右上角配置模型 Key。

启动

  1. 打开 ArcMap。
  2. 点击工具栏“启动AI后台”。
  3. 点击“显示控制台”打开 GeoPilot 页面。
  4. 点击“同步上下文”，让页面读取当前地图图层。

模型配置

半代理模式默认使用 DeepSeek。全代理模式默认使用 MiniMax。Key 只保存在当前 Windows 用户目录。

配置入口：页面右上角 配置模型。

执行任务

  1. 在对话框输入任务。
  2. 查看生成的任务卡片。
  3. 确认后发送到 ArcGIS。
  4. 回到 ArcMap 点击“执行工作流”。

两种模式

  • 半代理模式：适合单次任务，例如缓冲区、相交、选择、导出。
  • 全代理模式：需要先创建项目工作目录，后续会优先在该目录中查找数据并保留项目记忆。

工具进化

如果当前能力不够，GeoPilot 可以生成“待审核工具包”。启用前它不会进入 ArcMap 执行目录。

常见问题

  • 页面打不开：先在 ArcMap 点击“启动AI后台”。
  • 地图不对：点击“同步上下文”。
  • 任务没执行：确认任务后，还要回 ArcMap 点击“执行工作流”。

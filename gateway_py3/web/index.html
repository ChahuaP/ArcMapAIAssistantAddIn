版本日志

GeoPilot 完整发布历史。

1.0.0 2026-06-03 ~ 06-04
  • 重构 Web 控制台为"指令工作台"布局，移除多 ArcMap 选择 UI
  • 拆分语音识别与指令校验为独立流程
  • 前端全面重设计：OKLCH 色彩体系、新排版与组件样式
0.21.x 2026-06-02
  • 支持阿里百炼 Token Plan API Key
  • 新增 Provider Key 清除功能
  • 修复旧配置无法通过网页保存的问题
  • 统一路径处理，增强自定义工具 Unicode 路径与网络错误提示
0.20.x 2026-06-02
  • 新增阿里百炼模型支持及多版本 ArcMap 插件安装
  • 增强卸载功能
  • 移除项目系统，全代理模式改为会话模式
  • 新增空要素图层和矩形面创建操作
  • 重构 workflow 工具接口为 JSON 字符串格式
0.14.x 2026-06-01
  • 简化 ArcMap Add-in 工具栏为单一控制台按钮
  • 添加语音识别功能并重构为事件流架构
  • 支持批量创建几何要素和向已有图层追加要素
0.13.x 2026-05-23 ~ 05-31
  • 新增几何创建、版面导出和数据管理操作集
  • 完善 Agent 诊断能力
  • 新增制图操作包与 KML 导出，增强栅格图层加载
  • 重构 KML 导出功能，移除 cartography 模块
0.12.x 2026-05-23 ~ 05-30
  • 简化发布流程，改用纯安装器交付，重构运行时路径配置
  • 新增外部 ArcMap Bridge 和外部 Agent API 支持
  • 添加智谱模型支持及多项改进
  • 增强自定义工具验证与修复反馈机制
  • 支持多格式输出策略、KMZ 拆分导出、输出文件夹解析
  • 支持中文 output_name，移除时间戳后缀
  • 强制 AI 模型在写数据步骤中自行决定 output_name
0.11.x 2026-05-22
  • 发布 GeoPilot 0.11.13
  • 完成全代理后端
  • 新增完整用户安装包构建与卸载系统
  • 校验属性查询操作符
0.10.x 2026-05-20 ~ 05-21
  • 重构网关为 Agentic Planner，支持 DeepSeek 工具调用
  • 新增底图能力、属性表直接编辑、结构化条件查询
  • 重构上下文同步策略，支持显式输出位置和通用追问逻辑
  • 新增按字段唯一值拆分导出功能
  • 新增诊断与安装自检功能
  • Windows 安装脚本兼容性修复
初始版本 2026-05-19
  • 初始提交 ArcMap AI Assistant 完整项目
